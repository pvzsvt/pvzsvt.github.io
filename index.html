C++ 控制台小游戏 - 扫雷

目前仅支持 Windows，可二创

玩法：控制台交互，地图是一格占一个字符的，通过按键移动“当前选择格”并执行操作，支持可滚动的超大地图（最大100*200）。详见游戏内帮助。

下载时若被系统或浏览器拦截称有风险（因为它来自互联网且没有数字签名）：
  • 浏览器: 进入下载页面并点击保留。
  • 系统: 右键进入属性，勾选下方“解除锁定”，应用并确定。
（如果你不信任的话你自己编译）

1.0

依赖 Windows 经典控制台，检测到现代 WT 会自动重启切换，（因为现代 WT 的特性导致它有一些难以解决的 bug）
若出现循环切换窗口、难以关闭的问题，长按 delete 停止切换！

  • CPP UTF-8编码 (适合现代编辑器如 VS Code)
  • EXE GBK编码 (Windows中文终端默认编码)
